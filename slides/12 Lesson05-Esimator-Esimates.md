Before proceeding, we clarify the concept of an estimator.



**Estimate:** A value calculated from observed data.

**Estimator:** A random variable defined by applying the same formula to the underlying random variables.



If the experiment were repeated, the estimate would vary from sample to sample.  
The estimator describes the distribution of these possible estimates.



In the following, we will often use the same symbol for the estimate and the estimator.  
The meaning will be clear from the context.



Using this definition, we can now introduce the concept of **unbiased estimates**.
